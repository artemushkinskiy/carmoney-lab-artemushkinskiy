# Intent MILEAGE: пробег авто больше 400 000 км — решение review

ID задачи: MILEAGE. Интервью Grill Me: docs/intent/grill_MILEAGE.md.

## 1. Замысел

Добавить в расчёт решения по заявке проверку пробега авто:

- пробег не больше 400 000 км — решение по заявке не меняется;
- пробег больше 400 000 км — решение review;
- пробег в заявке обязателен: пустое значение — ошибка валидации, до расчёта решения заявка не доходит.

## 2. Зачем

Сегодня решение по заявке зависит только от LTV, пробег в решении не участвует (код: backend/src/Domain/DecisionEngine.php). Из-за этого заявка на авто с большим пробегом может получить approve. Правило закрывает этот пробел: при пробеге свыше 400 000 км решение — review, а не approve.

## 3. Constraints

- Порог: «пробег не больше 400 000 км, иначе решение review». — ответ в интервью (формулировка задачи)
- Граница включительно: ровно 400 000 км решение не меняет; review — только при пробеге больше 400 000 км. — ответ в интервью
- Пробег обязателен: пустое значение — ошибка валидации. Сегодня отсутствие значения — уже ошибка валидации, а пустая строка нормализуется в 0 км и проходит как 0 км. — ответ в интервью; код: backend/src/Domain/ApplicationValidator.php
- Действующая валидация пробега: от 0 до 500 000 км, при нарушении — ошибка валидации. Поэтому новое правило фактически работает в диапазоне «больше 400 000 и не больше 500 000 км»: заявки с пробегом свыше 500 000 км до решения не доходят. — код: backend/src/Domain/ApplicationValidator.php, backend/config/rules.php
- Решение сегодня принимается только по LTV: меньше 60% — approve, от 60% до 85% — review, больше 85% — reject. — код: backend/src/Domain/DecisionEngine.php, backend/config/rules.php
