# Что изменилось в README

Добавил раздел «Как проверить, что сервис жив» и две строки в таблицу команд — `make ps` и `make logs`. В самом разделе три команды по возрастанию глубины: `make ps` показывает состояние контейнеров, `curl /health` дёргает health-эндпоинт (с учётом `APP_PORT`), `make logs` смотрит поток логов backend. Заметил, что в `docker-compose.yml` healthcheck задан только для `db`, а для `backend` — нет, и честно записал это ограничение в README.
